# 数学小助手 · 小学四年级 AI 数学辅导（学生端 + 家长端）

一个面向小学四年级的数学辅导项目，双端设计，**两端都能脱离微信开发者工具运行**：

- **学生端**，孩子使用：📷 拍照识题、🧮 分步引导练习、📕 错题本
  - 微信小程序版（`pages/`，在手机上用微信打开）
  - **网页版（`student-web/`，任何浏览器直接打开，无需微信）** ← 与小程序共用同一份解题引擎
- **家长端（纯网页）**，家长使用：浏览器打开即可，凭同步码查看孩子的练习进度、正确率、错题和薄弱知识点
- **同步后端（可选）**：学生端（小程序/网页均可）每次练习后自动上报，家长端实时查看

**零配置即可体验**：学生端内置"本地解题引擎"，覆盖四年级常见题型（三位数乘两位数、除数是两位数的除法、四则混合运算、简便计算、小数加减法、行程/购物/归一/平均数/鸡兔同笼/长方形周长面积等），未接入任何 AI 接口时也能完整演示；家长端内置"演示数据预览"，不启动后端也能看到界面效果。

## 从 GitHub 获取（其他设备）

在任意装有 Git 的设备上：

```bash
git clone https://github.com/sought-sudo/math-tutor-miniapp.git
```

也可以在仓库主页点绿色「Code」按钮 →「Download ZIP」下载压缩包解压。项目已带 `.gitattributes` 统一行尾，Windows / macOS / Linux 克隆后都能直接在微信开发者工具中导入运行（AppID 使用测试号或游客模式即可）。

## 快速开始

### 学生端（网页版，不需要微信开发者工具）

1. 启动后端（Node ≥ 18）：

   ```bash
   node server/server.js
   ```

2. 浏览器打开 **http://127.0.0.1:8787/student**（也可以直接双击 `student-web/index.html`）
3. 完整支持：每日练习分步引导、拍照/选图识题（后端配视觉模型时）、错题本、家长同步码
4. 打开根地址 **http://127.0.0.1:8787/** 可看到学生端/家长端入口选择页

> 网页版学生端与小程序版共用 `utils/solver.js` 解题引擎（后端以 `/student/solver.js` 提供），行为完全一致。

### 学生端（微信小程序）

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开工具 → 「导入项目」→ 选择本目录
3. AppID 选择「测试号」或「游客模式」即可
4. 编译运行，从首页的「每日练习」开始体验

### 家长端（网页，不需要微信开发者工具）

1. 启动后端（Node ≥ 18）：

   ```bash
   node server/server.js
   ```

2. 浏览器打开 **http://127.0.0.1:8787/parent**（也可以直接双击 `parent-web/index.html`）
3. 输入孩子小程序「家长端」页显示的 6 位同步码 → 查看进度
4. 没有后端/同步码时，点「用演示数据预览」看界面效果

> 家长端在任何设备（电脑/手机/平板）的浏览器都能打开。公网部署后，家长在外也能随时查看（见下文「家长端同步」）。

## 三种运行模式

### 模式一：纯本地演示（默认，开箱即用）

`utils/config.js` 中 `llm.enabled` / `ocr.enabled` / `sync.enabled` 均为 `false`：

- 学生端练习、错题、家长端入口页全部可用，数据只保存在本机
- 拍照后需手动输入题目文字（页面会提示，也提供示例题）
- 家长端网页可用「演示数据预览」查看界面

### 模式二：家长端同步（推荐先试这个）

1. 启动后端：`node server/server.js`
2. `utils/config.js` 打开同步开关：

   ```js
   sync: { enabled: true, baseUrl: 'http://127.0.0.1:8787' }
   ```

3. 孩子在小程序里练习（错题/掌握/删除都会同步）；家长打开 `http://127.0.0.1:8787/parent`，输入小程序「家长端」页显示的同步码即可查看进度

同步数据保存在 `server/data.json`（已加入 .gitignore，不会提交到仓库）。

**公网部署**：把 `server/server.js` 部署到任意有公网地址的 Node 主机（或使用内网穿透），小程序 `sync.baseUrl` 填公网 https 地址，家长在任何设备浏览器打开 `https://你的域名/parent` 即可随时查看。

### 模式三：真实 AI 模式（可选）

1. 启动后端并配置大模型：

   ```bash
   # Windows CMD
   set LLM_BASE_URL=https://api.deepseek.com
   set LLM_API_KEY=sk-xxxx
   node server/server.js

   # 识图需另设支持视觉的模型（Qwen-VL / GLM-4V / GPT-4o 等）
   set OCR_MODEL=qwen-vl-plus
   ```

2. `utils/config.js` 填入后端地址并打开 `llm.enabled` / `ocr.enabled`
3. 真机上线时，需在微信公众平台把后端域名加入 request 合法域名（要求 HTTPS）

## 关键设计

- **双端分离**：学生端专注练习（小程序），家长端专注监督（网页），互相不干扰；家长端不需要装任何东西，浏览器即可
- **同步码机制**：学生端首次使用自动生成 6 位同步码，家长端凭码查看，无需注册账号
- **数据分层**：学生端数据保存在微信本地存储；开启同步后，练习记录和错题变化实时上报后端（失败静默忽略，不影响学习）
- **辅导闭环**：作答错误两次 → 显示正确答案并自动加入错题本 → 错题本「再练一次」→ 做对自动标记"已掌握"
- **答题宽容度**：答案比较容差 0.01；支持直接输入算式（如 `125×8+25×4`）；答案含文字的题型（鸡兔同笼）改为"自我核对"
- **本地引擎可自检**：`node scripts/check-solver.js` 批量生成题目并验证答案

## 常见问题

- **提示基础库版本过低**：在开发者工具「详情 → 本地设置」调高调试基础库（项目配置为 3.3.4）
- **相机黑屏/无权限**：真机需授权相机；开发者工具中相机为模拟画面，也可用「从相册选择」
- **家长端网页打不开/加载失败**：确认后端已启动（`node server/server.js`），且浏览器地址与后端地址一致；直接双击打开 HTML 时，后端地址填 `http://127.0.0.1:8787`
- **家长端看不到最新进度**：确认小程序 `utils/config.js` 里 `sync.enabled = true` 且 baseUrl 正确；点家长端「刷新」按钮
- **后端连不上（小程序）**：确认勾选「不校验合法域名」，且后端已启动在 8787 端口
